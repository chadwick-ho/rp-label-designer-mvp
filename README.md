# RP Online Vial Label Designer MVP

A free browser-based prototype for creating custom 3 mL and 10 mL vial label concepts.

## Features

- Live flat-label and photorealistic vial previews
- Editable product, strength, batch, expiry, and QR fields
- Six original label templates
- White BOPP, silver holographic, and prism holographic previews
- Logo upload and positioning
- Local draft saving and PNG preview download
- No account, payment, or API key required

## Local preview

Open `index.html` directly, or serve the directory with any static web server.

This is a review prototype and is not yet integrated into the production website.
